# Msc-Data-science

## Overview
Coursework using PySpark to predict payment type from NYC Yellow Taxi Trip Records for 2024.

## Dataset
- Source: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
- Original dataset: 41,169,720 rows and 19 columns.
  
## Notebooks
- Task1: Dataset inspection and Big Data justification.
- Task2: Cleaning, feature engineering and preprocessing.
- Task3: Four classifiers and cross-validation.
- Task4: Spark UI, caching and partition experiments.
- Task5: Evaluation, stability analysis and SHAP.
- Task6: Data preparation for Tableau.

## Models used
Logistic Regression, Random Forest, One-vs-Rest Gradient Boosting and XGBoost.

## How to Run
Run Task1–Task6 in order in Google Colab.

## Tableau
Four dashboards cover data quality, model performance, business insights, and scalability/cost analysis
